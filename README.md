# لِباس — متجر ملابس تجريبي

واجهة متجر إلكتروني عربية لعرض الملابس والأحذية والإكسسوارات، بتصميم متجاوب مع الهاتف والكمبيوتر.

## تشغيل الموقع

الموقع واجهة ثابتة مبنية بـ HTML وCSS وJavaScript، ولا يحتاج إلى Python أو خادم محلي:

1. افتح `index.html` مباشرة في المتصفح، أو انشر المستودع باستخدام GitHub Pages.
2. عدّل قائمة المنتجات والصور والأسعار والمقاسات من مصفوفة `products` داخل `index.html`.

## الخصائص الحالية

- أقسام للنساء والرجال والأطفال والأحذية والإكسسوارات.
- عرض المنتجات مع البحث والتصفية والترتيب حسب السعر.
- صفحة تفاصيل لكل منتج مع اختيار المقاس واللون.
- سلة مشتريات مع تعديل الكميات وحفظها محلياً في المتصفح.
- قائمة مفضلة.
- نموذج إتمام طلب تجريبي يجمع بيانات التوصيل وينشئ ملخصاً قابلاً للنسخ.

## ملاحظات مهمة

- المنتجات والأسعار والصور الحالية أمثلة تجريبية وليست مخزوناً حقيقياً.
- السلة والمفضلة محفوظتان في متصفح الزائر باستخدام Local Storage.
- نموذج الطلب لا يرسل الطلب إلى خادم، ولا توجد بوابة دفع أو إدارة مخزون أو لوحة تحكم حالياً.
- لإطلاق متجر فعلي، يلزم ربط الواجهة بقاعدة بيانات وواجهة خلفية لإدارة المنتجات والطلبات، وإضافة وسيلة تواصل ودفع وشحن حقيقية.
- الصور الحالية تُحمّل من Unsplash، والخط من Google Fonts؛ يتطلب عرضها اتصالاً بالإنترنت.

## التخصيص

ابحث داخل `index.html` عن `const products = [...]` لتعديل:
- اسم المنتج والقسم والوصف.
- السعر والسعر السابق.
- رابط/معرّف الصورة.
- المقاسات والألوان.
