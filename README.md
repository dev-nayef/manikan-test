# Old School — متجر ملابس رجالية

واجهة متجر إلكتروني عربية لعرض الملابس والأحذية الرجالية. المتجر يعمل كواجهة بيع/وسيط لعرض منتجات من موردين أو بائعين، ولا يدّعي تصنيع المنتجات أو امتلاك علامة تجارية للمنتجات المعروضة.

## تشغيل الموقع

الموقع واجهة ثابتة مبنية بـ HTML وCSS وJavaScript، ولا يحتاج إلى Python أو خادم محلي:

1. افتح `index.html` مباشرة في المتصفح، أو انشر المستودع باستخدام GitHub Pages.
2. عدّل قائمة المنتجات والصور والأسعار والمقاسات من مصفوفة `products` داخل `index.html`.

## الأقسام

- تيشيرتات رجالية.
- قمصان رجالية.
- بناطيل رجالية.
- جاكيتات رجالية.
- أحذية رجالية.
- عروض وتخفيضات.

## الخصائص الحالية

- واجهة عربية RTL ومتجاوبة مع الهاتف والكمبيوتر.
- عرض المنتجات مع البحث والتصفية والترتيب حسب السعر.
- تفاصيل المنتج مع اختيار المقاس واللون.
- سلة مشتريات مع تعديل الكميات وحفظها محلياً في المتصفح.
- قائمة مفضلة.
- نموذج طلب يجمع بيانات العميل وينشئ ملخصاً للمراجعة.

## ملاحظات مهمة

- المنتجات والأسعار والصور الحالية أمثلة تجريبية وليست مخزوناً أو عروضاً مؤكدة.
- يجب تأكيد توفر المنتج والمقاس واللون والسعر مع العميل قبل اعتماد الطلب.
- السلة والمفضلة محفوظتان في متصفح الزائر باستخدام Local Storage.
- نموذج الطلب يحفظ نسخة محلية في Local Storage، ويمكن للوحة الإدارة قراءتها من المتصفح نفسه فقط. لا يوجد خادم أو مزامنة بين الأجهزة أو بوابة دفع.
- لإطلاق متجر فعلي، يلزم ربط الواجهة بنظام لإدارة المنتجات والطلبات، وإضافة وسيلة تواصل وشحن ودفع مناسبة.
- الصور الحالية تُحمّل من Unsplash، والخط من Google Fonts؛ يتطلب عرضها اتصالاً بالإنترنت.

## التخصيص

ابحث داخل `index.html` عن `const products = [...]` لتعديل أسماء المنتجات وأقسامها وأوصافها وأسعارها وصورها ومقاساتها وألوانها.


## لوحة الإدارة

افتح `admin.html` من نفس النطاق والمتصفح لإدارة المنتجات والمحلات ومراجعة الطلبات المحفوظة محلياً. هذه ليست مصادقة آمنة؛ لا تستخدمها لإدارة بيانات حقيقية أو حساسة قبل إضافة Backend وتسجيل دخول من جهة الخادم. بيانات Local Storage لا تنتقل بين أجهزة الزوار.
